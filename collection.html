保存到 GitHub

    将更新 jiafei-36/jiafei-36.github.io 的收藏目录，内容会公开，并保留在 GitHub 提交历史中。

    首次使用：创建 GitHub 授权令牌
    1. 打开 GitHub 创建令牌，使用 jiafei-36 账号。
    2. Repository access 选择 Only select repositories，只勾选 jiafei-36.github.io。
    3. 确认 Repository permissions 中 Contents 为 Read and write，然后点击 Generate token。
    4. 复制生成的令牌，回到此处填写。令牌过期后需要重新创建。

    仅发送给 GitHub；不保存在浏览器或网站中。不要在聊天里发送令牌。
