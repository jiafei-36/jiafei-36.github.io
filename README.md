# 倪嘉晖的个人网站

网站：https://jiafei-36.github.io/

- `index.html`：个人介绍与联系方式。
- `math.html`：数学页面，提供近期工作入口。
- `recent-work.html`：近期工作介绍。
- `reviews.html`：评论与推荐，正文暂时留空。
- `github-avatar.jpg`：GitHub 头像，用作网站图标和页头标识。

公共样式位于 `styles.css`。网站无需构建，由 GitHub Pages 从 `main` 分支根目录发布。

## 导航与内容约定

- 链接使用纯文字，不在前后添加装饰性箭头；以后新增链接也遵循这一约定。
- 数学导航支持鼠标悬停和键盘聚焦展开子页面；触屏首次点击展开，再次点击进入数学页。
- `teaching.html`：助教经历。
- `navigation.js`：下拉导航交互。
